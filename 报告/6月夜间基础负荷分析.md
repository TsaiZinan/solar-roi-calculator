# 6月夜间基础负荷分析

- 目标：按新规则识别真正的夜间基础负荷。
- 夜间定义：`18:00-23:59` 与 `00:00-05:59`。
- 严格筛选条件：`光伏功率 <= 0.5kW`、`订单充电功率 <= 1.0kW`、`|储能功率| <= 3.0kW`，且整小时 12 个 5 分钟点全部满足。
